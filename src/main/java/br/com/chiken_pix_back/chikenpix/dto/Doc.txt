dto = Data Transfer Object

Define os contratos de entrada e saída de dados da API.
Isola as entidades do banco de dados, aplicando validações e filtrando campos sensíveis.

EX.:
ProdutoRequestDTO.java: Recebe nome, descricao e preco,
    de uma requisição feita do cliente para cadastrar um produto.

ProdutoResponseDTO.java: Retorna os dados formatados do produto, sem expor metadados internos do banco.
